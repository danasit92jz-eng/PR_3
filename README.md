## Project Name
Student Data Organizer – Student Record Management System
## Objective
The project manages student records using Python collections.
The project demonstrates the use of List, Tuple, Set, Dictionary, string manipulation, type casting, and match-case statements.
## Features
### 1. Add Student
The program accepts Student ID, Name, Age, Grade, Date of Birth, and Subjects.
### 2. Display All Students
The program displays all student records.
### 3. Update Student Information
The program updates the student's Age, Grade, or Subjects.
### 4. Delete Student
The program deletes a student record using Student ID.
### 5. Display Subjects Offered
The program displays all unique subjects in alphabetical order.
### 6. Menu-Driven Interface
1. Add Student
2. Display All Students
3. Update Student Information
4. Delete Student
5. Display Subjects Offered
6. Exit

## Technologies Used
- Python 3
- List
- Tuple
- Set
- Dictionary
- String Manipulation
- Type Casting
- for loop
- while loop
- match-case statement
- if-else statements## How to Run
### Step 1: Install Python
Install Python 3 on your computer.
### Step 2: Download or Clone the Repository
Download this project from GitHub or clone the repository.
### Step 3: Open the Project Folder
Open the project folder in IDLE editor.
### Step 4: Run the Program
Open the terminal and execute:pr_3_final.py
